# GramSetu

A modern responsive website concept for connecting rural communities with services, education, employment and opportunities.

## Run
No XAMPP is required.

Simply open `index.html` in a browser, or use VS Code Live Server.

## Files
- `index.html` — main landing page
- `blog.html` — blog/journal page
- `style.css` — complete responsive styling
- `script.js` — scroll reveal and mobile navigation

This is a front-end demo. Backend/database features can be added later.
